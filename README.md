# 2D 即时战略原型 v0.3

原生 Python + pygame 开发的 2D RTS 原型，仿《红色警戒》《铁锈战争》《王国保卫战》风格。

## 运行

```
pip install pygame
python game.py
```

或双击 `启动游戏.bat`。

## 操作

| 操作 | 功能 |
|---|---|
| 鼠标左键拖框 | 选定单位 |
| 鼠标右键 | 移动命令 / 攻击移动 |
| 鼠标中键拖动 | 拖屏 |
| 鼠标滚轮 | 缩放地图 |
| 右上角齿轮 | 操作说明 |
| 双击同类 | 全选画面内同类单位 |

## 已实现功能

### 核心系统
- **地图**：3600×2600 世界坐标，A* 寻路（二叉堆），中键拖屏，滚轮缩放（0.5x~2.0x），小地图+缩放条
- **单位**：工兵（可建造）、步兵（近战）、敌步兵、英雄、坦克
- **建造**：工兵选定后可建造兵营/炮塔/仓库，兵营可生产步兵（消耗时间）
- **碰撞**：硬碰撞 + 对称分离力，软碰撞容忍（5%~15% 半径重叠，按 zoom/视野调整），视野外降速至 85%

### 近战战斗系统（参考铁锈战争虫族逻辑）
- **索敌**：80px 内自动接战，一对一优先匹配，多对一时直接围攻（无方向槽）
- **接战**：A* 寻路追击，贴脸（两半径和）后停下转身攻击
- **攻击**：5 帧动画循环，每完成一轮扣一次血，HP 100，伤害 12，攻速 0.5s/刀
- **脱战**：追击超过 400px 放弃；玩家命令移动后走到目标前不自动接战
- **软碰撞**：战斗单位之间推到两半径和×0.88（约 12% 重叠），不穿模也不硬推
- **朝向**：移动不转身，贴脸攻击时才转身（moveIgnoringBody 风格）
- **血条**：可在设置中开关

### 素材
- 四族半俯视卡通步兵素材（human/orc/dwarf/undead），每族 3 动作×5 帧（walk/attack/die）
- 自动抠图（chroma key + 边缘羽化）

## 技术栈
- Python 3.12 + pygame 2.6
- A* 寻路（二叉堆，GRID=48）
- 空间桶（96px）加速碰撞/索敌
- 模拟时钟（`_combat_t`）替代墙钟，暂停时不累积

## 已知限制
- 远程单位（坦克）尚未接入战斗系统
- 三状态 UI（积极/守卫/撤退）仅 UI 占位，未实现逻辑
- 四族素材仅 human/orc 接入，dwarf/undead 待接入
